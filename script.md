# Steps to Configure and Run PowerShell Scripts for MSSQL Monitoring 

### Create the PowerShell Script 
- Create the monitoring script using the .ps1 file extension, which is required for PowerShell scripts. 

### Create the textfile_inputs Directory 
- Inside the Windows Exporter installation directory, create a folder named textfile_inputs. 
-  This directory is used to store the output files (.prom) generated by the PowerShell scripts for metric collection. 

### Create a Script Repository Directory 
- Create a directory named mssql_script on the desktop to centrally store all MSSQL-related PowerShell scripts. 

### Run the Script Manually (Validation Step) 
- Execute the master script manually to validate functionality: 

```bash 
powershell -ExecutionPolicy Bypass -File C:\Users\ShubhamPrasad\Desktop\mssql_script\master_runner.ps1 
``` 

### Schedule the Script to Run Every 1 Minute 
- Use the following command to create and run a scheduled task that executes the script every minute: 
``` bash
schtasks /create /tn "mssql_lt_master_metrics" /tr "powershell.exe -NoProfile -ExecutionPolicy Bypass -File `"C:\Users\ShubhamPrasad\Desktop\mssql_script\master_runner.ps1`"" /sc minute /mo 1 /ru "AzureAD\ShubhamPrasad" /rp * /f; `
schtasks /run /tn "mssql_lt_master_metrics"; `
Start-Sleep -Seconds 3; `
schtasks /query /tn "mssql_lt_master_metrics"
 ```

### View Existing Scheduled Tasks 
- To list all MSSQL-related scheduled tasks: 
``` bash 
schtasks /query | findstr mssql 
 ```

### Delete a Scheduled Task 
- To remove an existing scheduled task: 
``` bash 
schtasks /delete /tn "mssql_slow_queries_metrics" /f 
 
```
